## Component-game synthesis

`DistributedSynthesis.Results.ComponentGames` is the public import for the paper's
constructive decidability proof. Its namespace is `Characterisation.ComponentGames`.
The [module guide](../../DistributedSynthesis/Formalizations/ComponentGames/README.md)
contains executable-interface examples and the full paper-label correspondence.
Shared additions are `Library.Automata.FiniteController`,
`Library.Computability.FiniteOrders`, and `Library.Distributed.DecidableViews`.
The latter two expose scoped instances, so ordinary imports preserve existing orders.
